# Ember Agent (Hermes Field Agent)

Lightweight, portable field agent configuration for spare laptops, home, and work PCs.
Powered by [Hermes Agent](https://github.com/nousresearch/hermes-agent) running `glmflash` via `9router`.

## One-Line Install

```bash
curl -fsSL https://raw.githubusercontent.com/mirarenanovark/ember-agent/main/install.sh | bash
```

After install:
1. Add your `NINEROUTER_API_KEY` to `~/.hermes/.env`
2. Run `ember` (or `hermes`)

## Included Lean Skill Kit
- **`work-mode`**: Structured build/fix/deploy execution
- **`taste-skill`**: Design and taste calibration
- **`ponytail` & `caveman`**: Terse, efficient, stdlib-first coding discipline
- **`diagnosing-bugs` & `systematic-debugging`**: Root-cause triage
- **`disk-cleanup`**: Safe disk cleanup playbooks
- **`software-development`**: Minimal planning, TDD, and PR review

All bundled non-dev bloated skills are archived to keep initial token context ultra-lean.
